# Wolfi Security Tools

This directory contains tools for checking security vulnerabilities in Wolfi-based Superset images.

## Available Tools

### check-vulnerabilities.sh

Scans a Docker image for security vulnerabilities using Trivy.

```bash
# Check vulnerabilities in an image
./check-vulnerabilities.sh apache/superset:wolfi-latest

# Check with custom output directory
./check-vulnerabilities.sh apache/superset:wolfi-latest ./custom-output-dir
```

## Reports

The `reports` directory contains vulnerability scan reports generated by the tools in this directory.
